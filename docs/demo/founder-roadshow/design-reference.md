# NodeSlide roadshow design reference

Treat this as direction, not a rigid template.

- Format: 16:9, warm paper canvas, editorial restraint.
- Typography: a high-contrast editorial serif for decisive headlines; a neutral sans serif for body copy; monospace only for evidence labels, source IDs, formulas, and trace receipts.
- Palette: warm white and ink as the base, terracotta for human decisions, teal for validated evidence, indigo for machine activity.
- Layout: one argument per slide, generous whitespace, visible hierarchy, no tiny dashboard grids.
- Visual grammar: diagrams for mechanisms, charts for measured change, comparisons for before/after, and a single strong image only when it improves comprehension.
- Evidence: show compact source markers near the claim or visual they support; keep full provenance in the source and trace surfaces.
- Motion: none required. The deck should still communicate when exported to PowerPoint or PDF.
