## 2. Files changed / added

### convex/lib/

- **`piAi.ts`** — wraps `@mariozechner/pi-ai` `complete()` with:
  - `OPENROUTER_ATTRIBUTION_HEADERS` (`HTTP-Referer`, `X-Title`) on all
    OpenRouter calls — per OR's app-attribution docs, raises per-key
    rate-limit allocation
  - pi-ai built-in `maxRetries: 3` for transport-level 5xx/429
  - Soft-error retry loop (1s, 3s w/ jitter) catching the 200-with-
    error-body case OR uses for upstream 429s. Detected via
    `isRetriableError()` matching `/rate.?limit|upstream|429/i` on
    `errorMessage`.
- **`autoRouter.ts`** — VERIFIED-DATE comment expanded with run 2 data
  table comparing run 1 vs run 2; routing unchanged, `ling-2.6-1t:free`
  remains primary across all 7 free-tier phases with `claude-haiku-4-5`
  paid graceful-degrade fallback.

### scripts/ (recorder + stitcher)

- **`eval-free-models.mjs`** — added headers + retry loop on the
  evaluator, dropped deprecated `inclusionai/ling-2.6-flash:free`.
- **`record-end-to-end.mjs`** — scene 1: full pipeline E2E. Updated
  export step to click `<button name=Export>` then `<a role=menuitem>`
  for ZIP (was `<a name=Export>` before HeaderActions refactor); wraps
  `waitForEvent('download')` in `.catch(()=>null)` to prevent unhandled
  rejection on selector misses.
- **`record-scene-iterate.mjs`** — scene 2: v0.1.0 features. Replaced
  drag-bbox with `page.evaluate(window.postMessage(...))` mimicking the
  iframe element-click event shape `{ type: 'parity:element-click',
  rect, selector?, tagName?, text? }` that `CommentOverlay`'s
  `onMessage` handler listens for. Updated comment-textarea selector to
  match the actual placeholder ("Or write your own…").
- **`record-scene-mcp.mjs`** — scene 3: Playwright-rendered fake
  terminal cycling 5 hosted-Convex MCP tools with pre-recorded
  snapshots. Self-contained (no Convex required).
- **`stitch-demo.mjs`** — picks latest from each scene's `runs/`,
  applies per-scene `setpts=PTS/N` speed-up (defaults 6×/2.5×/1.2×),
  optional `MUSIC=auto`, optional `GIF=1` for palettegen+paletteuse
  output. Auto-drops music when speed > 1.
- **`make-music.mjs`** — synthesizes a 4-min C-major ambient pad via
  ffmpeg (sine layers + tremolo + lowpass + 3s/4s fade). MIT-clear, no
  network. Output: `runs/music/demo-bed-240s.m4a` (~900 KB AAC).

### docs/

- **`docs/plans/2026-04-29-free-model-eval.md`** — eval write-up,
  appended Run 2 results section comparing pre/post fix.
- **`docs/plans/2026-04-29-demo-recorder.md`** — demo trilogy plan

## 5. Re-running everything

### Re-run the eval

```bash
cd parity-studio
set -a && source .env.prod.local && set +a
export OPENROUTER_API_KEY=$(npx convex env get OPENROUTER_API_KEY)
export ANTHROPIC_API_KEY=$(npx convex env get ANTHROPIC_API_KEY)
node scripts/eval-free-models.mjs
# → runs/eval-free-<stamp>/{raw.jsonl, summary.md}
```

### Film a fresh demo

```bash
# Scene 1 — full pipeline (live prod, ~$0.50 per run)
node scripts/record-end-to-end.mjs

# Scene 2 — iterate features. Needs a populated RUN_ID.
# Grab one from scripts/record-end-to-end output OR:
node -e "fetch('https://blissful-pig-998.convex.cloud/api/query',{method:'POST',headers:{'content-type':'application/json'},body:JSON.stringify({path:'runs:listRecent',args:{limit:1},format:'json'})}).then(r=>r.json()).then(d=>console.log(d.value[0]._id))"
RUN_ID=<id> node scripts/record-scene-iterate.mjs

# Scene 3 — fake terminal, no env required
node scripts/record-scene-mcp.mjs

# Stitch (gif-style fast play, MP4 + GIF)
GIF=1 GIF_WIDTH=960 OUTPUT=runs/demo-$(date +%Y-%m-%d).mp4 node scripts/stitch-demo.mjs

# Smaller GIF for LinkedIn (<25 MB)
GIF=1 GIF_WIDTH=720 OUTPUT=runs/demo-$(date +%Y-%m-%d).mp4 node scripts/stitch-demo.mjs
```

### Slow-play with music (un-sped)

```bash
node scripts/make-music.mjs                                 # → runs/music/demo-bed-240s.m4a
SHELL_SPEED=1 ITERATE_SPEED=1 MCP_SPEED=1 MUSIC=auto \
  OUTPUT=runs/demo-slow.mp4 node scripts/stitch-demo.mjs
```

## 6. Known issues / future work

### Recorder edge cases (low priority, both have workarounds)

- **Scene 1 takes ~9:27 raw** because the artifact-detect heuristic
  (`hasArtifact = iframe.body.innerText.length > 80`) breaks early on
  the placeholder text but the pipeline keeps running through full
  decompose+verify. Stitcher's per-scene speed-up (`SHELL_SPEED=6`)
  hides this for the gif demo. To shorten the raw recording, tighten
  the loop to break on `parityScore >= 14/16` OR a hard 90s cap after
  artifact iframe first renders.
- **Scene 1 logs "Blocked script execution in about:srcdoc"** — the
  artifact iframe is sandboxed without `allow-scripts`, so React
  hydration warnings fire. Cosmetic; doesn't affect the recording.
- **Scene 2 advisor-executor reply may not fully stream** if the
  populated `RUN_ID` is still iterating in the background — the
  recorder competes with active backend turns. Use a known-stable
  RUN_ID (e.g., one with `status: done` and ≥30 files in `ui_kits`).

### Distribution / GTM (not yet started)

- **README hero** — embed `runs/demo-2026-04-29-fast-720.gif` after
  copying to `docs/media/`. Repo-relative GIF preview will appear on
  npmjs.com and on the GitHub repo home.
- **Landing page** — `parity-studio.vercel.app` should embed the MP4
  in its hero. Use `<video autoPlay loop muted playsInline>` with
  `poster=` set to a frame extracted at `~1:35` (the chat panel with
  enhanced prompt).
- **MCP catalogs** — `parity-studio-mcp` v0.1.0 not yet submitted to
  `mcpservers.org` or `cursor.directory`. See nodebench-ai's
  `memory/mcp_distribution.md` for the playbook.
- **Vertical (1080×1920) cut for LinkedIn/Twitter** — would crop scenes
  2 + 3 to portrait, splice the highest-impact 30s. Pure ffmpeg pass on
  existing assets, no re-record.
- **Self-dogfood** — generate the parity-studio landing page using
  parity-studio. "This site was generated by the tool it sells" is the
  highest-leverage marketing claim available.

### Eval / routing watchpoints

- `:free` slugs rotate during OpenRouter promotions. Re-run
  `scripts/eval-free-models.mjs` monthly. The VERIFIED-DATE comment in
  `autoRouter.ts` is the audit baseline.
- pi-ai 0.70.x bumps may rename slugs in `models.generated.js`. Check
  on pi-ai upgrades.
- If `ling-2.6-1t:free` rate-limits or deprecates, the fallback is
  `claude-haiku-4-5` (paid, ~$0.001/call) — graceful degrade. Consider
  adding `gemma-4-26b-a4b-it:free` as a sessionPick tertiary if free
  hosting becomes a hard requirement.
