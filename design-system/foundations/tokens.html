Token architecture — the app is themed by the system it sells

One W3C token format serves two namespaces. app.* is the studio's own identity and never changes. slide.* is only a default — a customer's SignatureProfile, extracted from their own decks, replaces it wholesale. Identity preservation is not a feature bolted on; it is where the theme system starts.

app.*

Studio chrome. Fixed, versioned with the product.

  • surface ladder #09090B → #1B2027
  • authorship inks: user / agent
  • receipt semantics: verified / warning / danger
  • type: Manrope · Inter · JetBrains Mono
  • 4px space scale · panel radius 14px

slide.*

Deck surface defaults. Overridable per deck, per team.

  • paper #FBF8F2 · terracotta rule lines
  • slide display + body families
  • replaced at render time by SignatureProfile
  • never leaks into app chrome
