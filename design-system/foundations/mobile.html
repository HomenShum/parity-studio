Mobile — the clay review surface

Derived from NodeRoom's mobile skin. Mobile is not an authoring surface: you read decks, review patches, and present. Paper becomes the whole app — cream and clay surfaces, ink-brown text, serif deck titles — and terracotta steps forward from accent to hero.

Terracotta deepens on clay. Desktop uses #D97757 on dark; mobile uses #C56A3C on cream for contrast, and spends it generously — active nav, card accent rails, primary actions, gradient logo marks. Type flips register too: DM Serif Display for deck titles and numbers, DM Sans for UI. Same receipt discipline, warmer voice.

Visibility language carries over from NodeRoom: private = slate, team = terracotta, mention = violet, shared = green. Maps directly onto deck sharing states.
